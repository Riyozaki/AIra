# AIra — третья попытка (v3)

**Тезис:** ум покупается петлями по времени, верификацией и учителем — а не весами.

Маловесная рекуррентно-глубинная языковая модель: 0.15–1.5B активных параметров в
тернарных (1.58-бит) весах, рассуждающая в латентном пространстве с адаптивной глубиной
на каждый токен, с внешней эпизодической памятью, инструментами и поиском на тест-тайме.
Цель — точка Парето «максимум рассуждения на грамм и ватт» с проверяемым публичным счётом.

## Документы

- [docs/ARCH_X1000.md](docs/ARCH_X1000.md) — **расчёт решения**: где физически живёт
  «мозговой ×1000» (спойлер: не в нейроне), бюджет множителей, цена открытия,
  матрица мозго-идей × кремний, стратегия «корабль и лаборатория» (3 слота-изобретения),
  письменный парк соблазнов. **Читать перед любым «давайте перепишем всё с нуля».**
- [docs/HARDWARE.md](docs/HARDWARE.md) — **контракт стандартного железа** (инвариант HW-0):
  инференс на серийном CPU без ускорителей; тиры T0–T3, арифметика скорости с внешней
  калибровкой, вердикты по каждому компоненту, ADR-001 (двухрежимная метрика E3).
- [docs/L1_SPEC.md](docs/L1_SPEC.md) — **слот L1 «блочно-событийное ядро»**: σ-δ долг-
  планировщик с доказанной границей T8′ (‖θ‖₂/(1−λ)), заморозка блоков FFN/слоёв внутри
  петель, денс-совместимые slice-GEMM ядра, обучение под события, протокол PB-01..PB-04
  с kill-правилами, бейк-офф против Spark-бейзлайна.
- [docs/THEORY_V3.md](docs/THEORY_V3.md) — **математические основания**: лемма уточнения
  (форма кривой «петли → ум» и шумовой пол), трёхосевой закон N×D×K, критик как
  оптимальное стоп-правило, двухшкальное усреднение с вычислимым m*, границы для
  тернарных петель и событийной остановки, бюджетная арифметика (Horowitz-константы),
  правило «знание ↔ веса». 12 предсказаний P-01..P-12, у каждого — эксперимент-убийца.
- [docs/RESEARCH_V3.md](docs/RESEARCH_V3.md) — инженерный ресёрч-документ: постмортем двух
  прошлых попыток, ландшафт 2026 года с цифрами, архитектурная спецификация,
  конвейер обучения, план на 90 дней с воротами и kill-критериями.
- [docs/SCOREBOARD.md](docs/SCOREBOARD.md) — **замороженный** измерительный лифт:
  метрики, бейзлайны, целевые уровни P1/P2/P3. Меняется только через ADR.

## Принципы третьей попытки

0. **Научный цикл:** теория → вычислимое предсказание (с числом) → расчёт →
   фальсифицирующий эксперимент → чекпоинт. Формулы без предсказаний не принимаются;
   эксперименты без теории-мишени не запускаются.
1. Capability-first: сначала чекпоинт, бьющий публичный бейзлайн, потом элегантность.
2. Один scoreboard, замороженный заранее. Прокси — только внутри эксперимента, никогда как результат.
3. Каждый эксперимент имеет заранее написанный kill-критерий и бюджет ≤72 часов.
4. Продукт итерации — обученный чекпоинт с цифрами в лифте, а не отчёт.
