# CDEMO_ADDENDUM_3 — R4: смена задачи на регистровую итерацию σ^h(x) (фиксированная σ)

**Дата: 2026-08-24, до прогонов R4. Родители: CDEMO_PROTOCOL, ADDENDA 1–2.
Протокольный статус: все три аддиктума — отладка СТЕНДА до первого протокольного
вердикта; ни один PC не исполнялся до отказа-но-продолжения, вердикты считаются
только по R4.**

## 1. Хронология стенда (честно, с числами)

| раунд | формат | итог | диагноз |
|---|---|---|---|
| R0 | flat-список π, лосс на 1 токене | все 4 плеча × 3000 шагов: acc ≈ 0.04 | разреженный надзор (1/46 токенов) |
| R2 | flat-список + chain-надзор | smoke 400 шагов random | то же |
| R2-diag | flat, только h∈{1,2}, D2, 1500 шагов | acc(h1)=0.089 | flat-adressing (значение→позиция) не выучивается |
| R3-diag | pairs (j,π(j)), h∈{1..2}, D2 | 800 шагов random | induction-shift: ответ в соседней позиции, 2 координированных внимания должны сойтись одновременно |
| sanity | тот же формат, фикс. батч | mem_acc=1.000 за 100 шагов | пайплайн исправен; болезнь — обобщение, не код |

Вывод: lookup-образование в мини-модели на 2 CPU — отдельная исследовательская яма
(grokking-масштаба), а не то, что мы измеряем. Проект измеряет ПЕТЛИ, а не адресацию.

## 2. Задача R4 — регистровая итерация (примитив тривиален, глубина настоящая)

- σ — ФИКСИРОВАННАЯ перестановка 32 значений (seed 999), одна на весь прогон.
- Сэмпл: x ∈ 0..31, h ∈ 1..12; вход [x, BLK×20]; таргет слота i = σ^i(x) при i ≤ h.
- Элементарный шаг σ — выучиваемая биграмма (одна на прогон, не per-sample таблица) —
  встаёт от FFN за сотни примеров. Задача = СОСТАВИТЬ её h раз.
- Анти-заучивание: (а) holdout 20% ячеек (x,h) в train, val_core ТОЛЬКО из них —
  запоминание ячеек мертво, нужна настоящая композиция; (б) расширение h∈[13,20]
  (вообще невиданные глубины) — PC-4R.
- Граунд-трут глубина = h точно; ширина не покупает состав σ^h без последовательности
  (проверяемо: D2 не должен обойти D8 — PC-2R).

## 3. Предсказания PC-1R..PC-7R действуют без изменений буквы

(фраза «чтение слота h» теперь относится к слотам регистровой цепи; остальное —
диета lognorm [2,16], K_eval {16,32}, пороги, кил-критерии — как в PROTOCOL + ADD.1).
