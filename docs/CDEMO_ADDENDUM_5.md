# CDEMO_ADDENDUM_5 — R6: охота за ≥20× (адаптивная глубина на перекошенной нагрузке)

**Дата: 2026-08-24, до прогонов R6. Родители: PROTOCOL + ADDENDA 1–4.
Постановка планки (заказчик): кратность <20× не является разговором; требуется
измеренная ≥20× на стенде — или задокументированная невозможность.**

## 1. Где ≥20× вообще может жить (анализ пяти похорон)

Убито: равномерная глубина (токен-ось/замкнутая форма съедают всё), пассивный критик
(Spearman 0.08). Осталось два механизма, которые обходы НЕ убивают:

а) **Перекошенная трудность** (реальные нагрузки: 95% запросов тривиальны, 0.5% —
   олимпиадные). Фиксированная глубина платит за худший случай всегда; адаптивная —
   по факту. Экономия = K_fixed/K̄_adaptive, теоретический потолок ≈ h_max/E[h] — у нас
   конструируется ≥25×. Это не трюк распределения: это и есть тезис TTC-движка проекта
   (SCOREBOARD «цена правильного ответа»), и он обязан быть измерен до заказчика.
б) **K-диета в обучении** (lognorm-хвост вместо фикс-K): стоимость шага K̄≈11 против
   48 — экономия обучающих FLOPs ×4+ при защите глубокого хвоста (наш G0S-актив ×5).

## 2. Дизайн R6

- Задача σ^h (R4-формат, слоты видимы, chain-надзор), расширенная: **h ∈ [1,48]**,
  R=48 слотов, обучение на ячейках (x,h) с holdout 20%.
- Диета: K ~ LogNorm(ln 8, 0.8) ∩ [4, 48] (K̄≈11, хвост кроет 48).
- Плечо одно: L (ln-ядро). 5000 шагов, d=96.
- **Критик C1 (обучаемый, новое):** после заморозки L собираем (k, признаки) с
  train-ячеек: d_k=‖h_k−h_{k−1}‖, cos(h_k,h_{k−1}), k, и логит-хвост; метка «ответ
  в слоте h уже верен на k». MLP 64→64→1 (sigmoid). Останов = первый k с p̂>0.5.
  Это мини-прототип A1-критика (A1_PLAN §4), только обучаемый — PC-12R убил
  пассивные прокси, не обучаемые.
- **Политики инференса на перекошенной валидации** (95% h∈{1,2}; 4.5% h∈{4..8};
  0.5% h∈{17..48}; 4096 сэмплов): fixed48; σ-правило (ε=0.05); критик C1; оракул
  (первый k, где ответ верен — верхняя граница).
  Теоретический оракул: E[K̄] ≈ 1.9 → экономия 48/1.9 ≈ **25×**.

## 3. Замороженные предсказания

- **PC-13R (способность).** L acc(h≤48)@K=48 на holdout ≥ 0.90.
  *KIL: <0.60 → глубина 48 недоступна этому рецепту/бюджету; цель переносится на
  меньший h_max с пересчётом кратности (revise один раз по числам, не по духу).*
- **PC-14R (ЗАГОЛОВОК ≥20×).** Политика C1 на перекошенной валидации:
  48/K̄_C1 ≥ 20 при падении acc ≤ 1 п.п. относительно fixed48.
  *KIL: экономия <10× или падение >3 п.п. → обучаемый критик не несёт заголовка
  даже на чистом стенде; T3 списывается в «внешний верификатор вместо критика»
  (крупная перестройка плана, фиксируется ADR).*
- **PC-15R (диета сторона).** Рецепт-диета против fixed-K=48 обучения (второе плечо
  контроля, тот же L, обученный с K≡48): равная acc(h≤16)@K=48 при отношении
  блоков-обучения ≥ 3.5×. *KIL: диета проигрывает acc > 2 п.п. → PC-15R снимается,
  диета остаётся только drift-защитой.*
- **PC-16R (зеркало).** σ-правило: экономия фиксируется как-есть (ожидание:
  K̄ выше C1 из-за PC-12R); Lsum-контроль не повторяется (два коллапса уже в архиве).
