# G0S_PROTOCOL — стенд G0: задача с настоящей глубиной (Sudoku 9×9)
Дата: 2026-08-24. Заморожено до обучающих прогонов. Основание: TWEEK_RESULTS R4
(лукап-конфаунд: CA r=8 проигран 17-битной таблице; правило «ширина съедает глубину»).

## 1. Задача (измерено до прогона, фиксируется)
Sudoku 9×9 методом выкапывания из полного решения: уникальность после КАЖДОГО удаления
(bactracking count==1), принятие только если решается чистой пропагацией (naked+hidden singles).
Граунд-трут глубина d* = число синхронных волн релаксации (одна волна = один параллельный
пропагационный проход = одна итерация петли модели). Пилот 100 выкапываний (36 с): d* ∈ {4..11},
медиана ~6–7; blanks 49–55 из 81. Лукап исключён: fan-in ячейки — вся доска.
Пулы (делаются один раз, кэшируются): train 1400, val 400; распределение d* фиксируется в results.
Бакеты: shallow d*≤5, deep d*≥7 (середина 6 — вне сравнения).

## 2. Конфиг
Модель: ln-ядро D-002 (`h ← LN(h + βf(h))`), d=64, d_ff=256, 4 головы, vocab=11, max_len=164.
Варианты: β=1.0, β=0.5. Обучение 3500 шагов, B=12, K_train ∈ [2,12], lr 3e-3,
глубокий надзор на всех k. Eval K=64, 400 строк val.

## 3. Предсказания (записаны до прогонов; кил-критерии при каждом)
- **S-1 (петли используются; TW-A1 redux).** acc_blank@16 > acc_blank@1 на ≥10 п.п. агрегатно;
  в deep-бакете разница ≥20 п.п. **Кил:** плоскость снова → петли не покупаются даже
  constraint-propagation задачей → эскалация: полный пересмотр зачем-петли на G0 (сначала
  проверить дизайн: K_train хвост / d_ff), потом стратегии.
- **S-2 (форма E(K), своя).** L_blank(K) на deep-бакете фитится «геометрия+пол», R²≥0.8,
  λ̂_E(K) ∈ [0.6, 0.95]. **Иначе:** своя кривая не подтверждает T1′-форму → расхождение с Parcae
  требует объяснения (масштаб? задача?), помечается в реестре.
- **S-3 (λ(x) — входной сигнал критика существует).** Spearman(τ_stab(x), d*(x)) ≥ 0.5;
  медианы τ_stab deep/shallow ≥ 1.5. **Кил:** ρ<0.3 → сигнала глубины нет в траектории →
  критик T3 лишается входа; проект критика пересматривается (учитывая внешний фейл halting
  у Retrofit — риск TO-3 стал бы критическим).
- **S-4 (перенос плато D-002).** Деградация acc_blank от k=16 до k=64 < 2 п.п. Иначе —
  плато CA было свойством задачи-фикспоинта, а не ядра: уточнение D-002 (нужна диета K_train
  в хвост, см. Parcae per-sample sampling).
- **S-5 (экономия оракула — билет T3).** K*(x) := первый k со стабильным argmax (равен K=64).
  E[K*] экономит ≥25% петель против минимального фиксированного K с той же точностью;
  потеря точности ≤0.5 п.п. (по построению 0). **Иначе:** распределение K* узкое и адаптивная
  глубина экономит мало — теза T3 теряет количественную опору на этом классе задач.
- **S-6 (задачо-зависимость λ̂).** λ̂_dir(β=1) на G0S ∈ [0.5, 0.8]. Значение вне диапазона —
  данные для PB-04 (перенос константы между задачами/масштабами): шкала переноса уточняется.
- **S-7 (β-чувствительность).** λ̂_dir(β=0.5) > λ̂_dir(β=1) (медленнее сходится), и acc_deep
  при K=16 ниже для β=0.5. Инженерное: калибровка шага β как ручки скорости сходимости.
