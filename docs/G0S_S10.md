# G0S_S10 — протокольное дополнение: инъекция входа (kernel v3)
Дата: 2026-08-24. Заморожено до запуска варианта `ln_big_waveinj`.

## Основание (три независимых внешних сигнала + самодиагноз)
1. Huginn: рекуррентное ядро получает входную инъекцию e НА КАЖДОЙ итерации (h_{k+1}=R(h_k, e)).
2. Retrofit-RD: «looping alone tends to drive activations off manifold. The input context
   must be re-injected on later iterations» — мост-реинъектор установлен обязательным.
3. Parcae: стабильность формулируется в терминах параметров ИНЪЕКЦИИ (B, prelude-norm).
4. Самодиагноз стенда: наша модель подаёт e только при k=0; при K=64 состояние уходит
   далеко за многообразие обученных входов без якоря. Кандидат на корень дрейфа 16→64
   (S-4 фейл) и медленного обучения.

## Вариант ln_big_waveinj
= `ln_big_wave` (d=96/384, lognorm K, волновой надзор) + единственное изменение ядра:
на каждой петле `h ← h + β·f(h) + j·proj(e)` с обучаемым per-channel скаляром j (init 0.1),
затем state-LN как раньше. Параметры proj: d×d (128К — 0.8% параметров).

## Предсказания S-10 (до запуска)
- **S-10a (якорь ломает дрейф):** acc64 − acc16 ≥ −2 п.п. (S-4 через инъекцию, не через
  один лишь хвост диеты). Если и хвост (ом ln_big) и инъекция не ломают дрейф —
  эскалация дизайна цикла (контекстные якоря явного вида / перезапуск состояния TRM).
- **S-10b (учебная скорость):** train loss при равных шагах ниже, чем у ln_big_wave,
  и acc_blank@16 выше на ≥ +5 п.п. (инъекция как хорошая, а не нейтральная добавка).
- **S-10c (взаимодействие сохранено):** если S-9a (волна ставит механизм) прошёл на
  ln_big_wave, то и на ln_big_waveinj deep gap остаётся ≥ +15 п.п.; если S-9a провалился,
  S-10 измеряет только (b)/(a) и НЕ воскрешает S-9a (одно изменение за раз двусторонне).
- Замороженная метка риска: LN-после-инъекции может частично стирать накопленное состояние
  (memory wash) — если acc32 >> acc16 (выраженная внутренняя не-монотонность), кандидат
  стабилизатора меняется: LN только инъекции, не состояния (Parcae-стылистика), вариант S-11.
