# G0S_S11 — протокольное дополнение: структурные эмбеддинги доски (row/col/box)
Дата: 2026-08-24. Заморожено до запуска варианта `ln_big_we` (если будет запущен).

## Основание
Линейная позиция не даёт вниманию дешёвого доступа к юнитам (строка/столбец/бокс) —
модель обязана выучить 2D-топологию с нуля за бюджет шагов, кандидат на причину
общего недоучивания (loss плато 1.65–1.8, acc_blank ≤0.25 на всех вариантах без исключения).
Структурные эмбеддинги — дарвиновски стандарт в sudoku-трансформерах и в N-queen/CSP литературе.

## Вариант ln_big_we (= ln_big_waveinj + структурные эмбеддинги)
К токен-эмбеддингу + pos добавляются три обучаемые таблицы: E_row[9], E_col[9], E_box[9]
(по позиции клетки для клеточных позиций; нулевой вектор на SEP). Параметры: 3×9×96 = 2.6К.
Единственное изменение против S-10.

## Предсказания S-11 (до запуска)
- **S-11a (разблокировка обучения):** train loss при 3500 шагах ниже соответствующего
  контроля на ≥0.3 ната; acc_blank@16 вырастает на ≥+10 п.п. против ln_big_waveinj.
- **S-11b:** если S-9a прошёл — сохраняется (deep gap ≥ +15 п.п.).
- **S-11c (порог вывода):** acc_blank@16 ≥ 0.40 — иначе недоучивание продолжается,
  и следующая гипотеза обязана быть про САМУ формулировку задачи (авторегрессия vs
  доска-за-петлю, TRM-формат: голова предсказывает всю доску из текущего состояния
  без авторегрессии ответов).
