# R3_PROTOCOL — m-sweep раунд 3 (стабилизированный медленный контур)
Дата: 2026-08-24. Заморожено до прогона. Основание: TWEEK_RESULTS §7.1 (раунды 1–2, premise fail дважды).

## Изменение аппаратуры (единственное)
TwoTimeCore: `s ← LN(s + slow(·))` (флаг `--slow_ln`, LN без аффинов, как ln-state у быстрого контура).
Всё остальное идентично раунду 2 (`--state_ln`): τ=10, m ∈ {1,2,4,8,16} + noslow, 1500 шагов, K_train∈[2,10], eval K=64.

## Предсказания (записаны до прогона)
- **TW-3-R3a (санити аппаратуры).** λ̂_L < 1 у всех m ≤ 8. Если нет — стабилизатор LN(s) недостаточен
  (s-карта противоречит сфере через инъекцию), следующий кандидат: tanh-ограничение FiLM. Продолжаем
  вниз по списку, TW-3 не оцениваем, пока аппаратура нестабильна.
- **TW-3-R3b (T4 по существу).** При λ̂_L(m=1) вычисляем m*_pred = ln τ / ln(1/λ̂_L).
  argmin_m L@K=64 ∈ [m*_pred/2, 2·m*_pred]. Иначе T4 опровергнута на стабилизированной аппаратуре →
  двухмасштаб паркуется до G0S-задачи (где медленный контур семантически необходим).
- **TW-3-R3c (медленный канал окупается?).** min_m L_slow < L_noslow − 0.3 ната. Иначе на этой задаче
  медленный канал не приносит силы (допустимо: задача почти безмасштабна) — фиксируем «не продано
  на tt-задаче» и переносим вопрос на G0S.
- Вердикт TW-3 финальный = R3b (при прошедшей R3a). R3c — самостоятельное измерение ценности канала.
