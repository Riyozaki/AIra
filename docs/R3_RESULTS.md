## Вердикты по замороженным предсказаниям
- **TW-3-R3a (аппаратура):** λ̂_L < 1 у всех m ≤ 8 (0.95–0.995) → **PASS**. LN(s) стабилизирует
  медленный контур; закон «каждый рекуррентный контур ограничен» подтверждён в третий раз с обратного
  знака: без LN(s) λ̂_L был 1.02–1.12 и весь канал вредил.
- **TW-3 (форма T4):** m*_pred = ln10/ln(1/0.953) = **48**, окно [24, 96] — вся решётка m≤16 вне его;
  argmin_m = m1. **FAIL по форме** (окно не содержит эмпирического оптимума), НО честная структура:
  λ̂_L≈0.95 — маргинальная стабильность, теорема отвечает «держи медленное почти замороженным»,
  что в решётке ≈ «каждый шаг» почти недостижимо-эквивалентно. T4 помечена: *предсказание породило
  m* вне измеримой сетки — для дискриминации нужна задача с семантически нужным медленным контуром*.
- **TW-3-R3c (канал окупается?):** noslow 2.977 << лучший slow 3.762 (Δ=+0.79 ната в пользу noslow,
  порог был −0.3). **FAIL: медленный канал НЕ продан** на tt-задаче. Диагноз (записан): в
  двухмасштаб-источнике медленная мода — Марковская с заменой: прошлая мода не информативна о новой,
  медленной памяти нечего запомнить. Канал нужен там, где существует медленное ПРЕДСКАЗУЕМОЕ состояние
  (иерархия, документ, маршрут).
