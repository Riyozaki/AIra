# SCOREBOARD v3 — замороженный измерительный лифт

**Статус: заморожен 2026-08-24.** Изменения только через ADR (документ в `docs/adr/`),
никогда — по ходу эксперимента. Это лекарство от болезни двух прошлых попыток:
«бесконечные тесты на придуманных прокси». Прокси допустимы внутри эксперимента,
но результатом итерации считается только строка этого лифта.

## 2. Ось «Эффективность»

| # | Метрика | Как меряем |
|---|---------|-----------|
| E1 | Размер весов, МБ | фактический файл (тернарная упаковка, embeddings отдельно) |
| E2 | Пиковая RAM при генерации, МБ | `/usr/bin/time -v`, фикс-контекст 4k |
| E3 | tok/s на CPU | фикс-машина: Ryzen 9 7840HS (8 потоков) и Raspberry Pi 5; batch=1, 512 токенов |
| E4 | tok/s на 1 GPU | A100-40GB, batch=1, генерация |
| E5 | Цена правильного ответа | loops·2·P_active·K̄ на токен → GFLOP/ответ; и $/correct через стоимость железа-часа |

## 4. Целевые уровни (цели проекта, не бейзлайны)

**P1 — доказательство оси (ворота G2):** наш AS-1 бьёт compute-matched dense-близнеца
на C1/C2/C6 при равных обучающих FLOPs, и кривая «качество vs число петель» монотонна
до K=8. Без этого — ось мертва, уходим в fallback-ветку (обычный SLM с сильной рецептурой).

**P2 — продукт (ворота G3):** 0.35–1.5B активных параметров, E1 ≤ 600 МБ, E3 ≥ 25 tok/s
CPU, и с TTC-движком: C1 ≥ 90, C2 ≥ 60, C3 ≥ 85, C4 ≥ 60 — коридор GPT-4o-mini /
«Opus-2024-класса» на верифицируемых доменах ценой малой модели.

**P3 — растяжка (ворота G4, убиваемо):** на верифицируемых доменах (математика, код,
логика) паритет с o1/Opus-4-классом по точности при цене правильного ответа (E5)
≤ 1/10 цены фронтир-API. Условие жизни P3: лог-линейный рост C2 от бюджета TTC на G2.

**Что НЕ является целью (записано, чтобы не переобещать себе):** общий чат и широта
знаний уровня Opus 5 в <1 ГБ; мультимодальность; агентные длинные горизонты; SOTA-статьи.
Знание фактов обеспечивается памятью/поиском (§9 RESEARCH_V3), а не весами.

- Запрещено: менять число шотов или подмножества «под результат», дропать регрессирующие
  метрики из отчёта, сравнивать с чужими цифрами без прогона на своём harness.
