## 0. Постановка и честное позиционирование

**Задача теории:** ответить на 5 вопросов ДО того, как сожжён первый GPU-час:

1. Почему петли по малому ядру вообще дают ум, и где их потолок? (T1, T2)
2. Сколько петель оптимально и кто это решает? (T3, T4, T8)
3. Как петли взаимодействуют с тернарными весами? (T5)
4. Сколько стоит токен и правильный ответ на этом субстрате? (T6)
5. Что хранить в весах, а что — снаружи? (T7)

**Позиционирование (честно):** ось N×D×K уже формализована чужими работами —
Parcae: Scaling Laws for Stable Looped LMs (arXiv 2604.12946) даёт
`L ≈ E + X·N(μ_rec)^(−x) + Y·D^(−y)` и Pareto-оптимальность лупинга при равных FLOPs;
Iso-Depth Scaling Laws (Schwethelm+, 2026) меряет «params-эквивалент петли»;
DeepLoop (arXiv 2607.13491) вывел loop-aware скейлинг резидуалов (α=(2N_g)^½, β=(8N_g)^(−½)
и показал, что тот же показатель p=½ валиден для иерархических рекуррентных резонеров);
LT2 (2026) совмещает петли с линейным вниманием; Looped-MoE — расходящуюся маршрутизацию
по петлям как спасение выразимости. **Наш вклад — не эти законы, а их стык с четырьмя
никем не занятыми предметами:** (а) квантизация × петли; (б) обучаемый критик как
принципиальная остановка (оптимальное стоп-правило, не эвристика); (в) двухшкальное
усреднение как источник обучаемых чекпойнтов поиска; (г) аллокация знания
веса↔память с числами; (д) бюджетная арифметика цены правильного ответа.
Формула вклада: **«цена ума» как функция (N, b, K(x), M) — и её минимизация.**

**Обозначения.**
`N` — параметры ядра; `b` — байт/параметр; `K` — петли ядра на токен (дизайн-глубина),
`K(x)` — реально потраченное (адаптивное); `D` — токены обучения; `M` — внешняя память
(фактов); `z ∈ R^d` — латент; `F` — оператор ядра (один шаг); `λ` — фактор сжатия F;
`δ` — шаговый шум (квантизация, усечения); `c` — теневая цена одной петли.

## T1 [Т]. Лемма уточнения: почему кривая «петли → ум» имеет вид, который мы сможем предсказать

**Предположения.** Оператор ядра F(·, x) — λ-сжатие на рабочем многообразии:
‖F(z)−F(z′)‖ ≤ λ‖z−z′‖, λ<1 (удерживается спектральными/DeepLoop-ограничениями, см. TO-5).
Ошибка задачи E(z) — κ-липшицева по z вокруг неподвижной точки z*.

**Утверждение.** Для чистых итераций z_k = F(z_{k−1}):
```
E(K) ≤ E* + κ‖z₀−z*‖·λ^(K)                ← лог-линейный спад, наклон ln λ
```
Для зашумлённых итераций z_k = F(z_{k−1}) + ξ_k, ‖ξ_k‖ ≤ δ:
```
E(K) ≤ E* + κλ^(K)‖z₀−z*‖ + κδ·(1−λ^(K))/(1−λ)
предел K→∞:  E∞ ≤ E* + κδ/(1−λ)             ← шумовой пол
```
**Доказательство (скетч).** Оба — развёртка ‖z_K−z*‖ ≤ λ‖z_{K−1}−z*‖ + δ по индукции
(геометрическая прогрессия, замкнутая сумма). ∎

**Что это даёт на практике (не декорации):**
- **Измеримый протокол λ:** по телеметрии ‖z_{k+1}−z_k‖/‖z_k−z_{k−1}‖ → λ̂ (медиана по k).
  Бесплатно, изнутри модели, в каждом логе обучения.
- **Форма кривой предсказана заранее:** качество vs K — лог-линейно, затем полка;
  полка задаётся НЕ «ёмкостью», а шумом и λ. Если на измерении кривая другая — T1 мертва.
- **Predicted взаимодействие с битами:** квантизация поднимает δ → поднимает полку
  в пропорции 1/(1−λ). См. T5.
- **Объяснение наблюдений чужих работ:** HRM/Huginn «сложным задачам нужно больше петель»
  = у сложных задач λ ближе к 1 (медленное сжатие) → K_эфф растёт как 1/ln(1/λ). Роутер
  сложности (§RESEARCH 4.3) обязан оценивать именно λ(x), не «тему задачи».

**Расчёт-пример A (будет воспроизведён на AS-0):** λ=0.72, κδ=0.03, нормируем e₀=1:

## T1′ [ИЗМ. 2026-08-24, T-неделя]. Предпосылка сжатия — не фон, а несущая часть теоремы

Измерено на стенде (docs/TWEEK_RESULTS §R1–R3, два независимых ядра, три метода):
- **Sum-ядро `h←h+βf(h)` без спектрального ограничения: λ̂ = 1+β точно (init) и навсегда
  (3000 шагов обучения не сдвигают: 2.0000±0.0001 у всех трёх методов).** Предпосылка T1
  «λ<1 удерживается спектральными ограничениями» переходит из сноски в обязательное ядро теоремы:
  без TO-5-подобного ограничителя T1 пуста, а T5/T8/L1-долг недействительны. Обучение сжатие
  НЕ рождает (гипотеза снята).
- **LN-ядро `h←LN(h+βf(h))`: подлинное сжатие направления λ̂_dir ≈ 0.586 (toy CA),** неподвижная

- **Метрическая поправка:** на расходящихся траекториях угловый дисплейсмент вырождается

Рабочее значение для всех λ-зависимых формул до прямого замера на AS-0 (TW-H): **λ̂ = 0.75**

## T2 [М]. Трёхосевой закон и честный ответ «почему K, а не N»

**Модель (стоим на Parcae).** L(N,D,K) = E + X·N(·)^(−x) эффективных + Y·D^(−y), где
эффективная ширина при μ петлях допускает их фит N_eff = N(μ_rec). Наша добавка —
два члена, которых ни у кого нет: квантизационный шумовой пол (T1) и стоимость:
```
L = E + X·(N·K^ρ)^(−x) + Y·D^(−y) + κδ(b)/(1−λ)        ρ ∈ (0,1) — «скидка переиспользования»
```
Привлекательно было бы верить: «K — бесплатная глубина». **Проверим честно [Т-отрицательный
результат]:** при фиксированных обучающих FLOPs C = 6NDK̄ и неадаптивном K эффективное N·K^ρ
при росте K только падает (N = C/(6DK̄) → N·K^ρ ∝ K^{ρ−1}). То есть **сама по себе петля
не выгоднее параметра** — в согласии с Iso-Deep-замерами «1 петля ≈ η < 1 свежих параметров
глубины». Выигрыш K живёт ровно в трёх местах, и мы обязаны пользоваться всеми тремя:

1. **Адаптивность [Т]:** K может зависеть от входа (K(x) ≤ K_max), N — никогда.
   Средняя цена E[K(x)] ≪ K_max при сохранении хвоста качества по сложным x. Формально:
   для распределения сложностей λ(x) политика K(x) = ln(δ/e₀(x))/ln λ(x) достигает той же
   средней ошибки, что и uniform-K, при средней цене, меньшей на фактор
   `E[K(x)]/K_uniform ≥ 1` (строго > 1, если Var(λ(x))>0 — док-во: Йенсен по ln).
2. **Асимметрия цен [Р]:** параметр живёт в памяти вечно (b байт × каждый токен), петля —
   микросекунды FLOPs при горячих весах. Количественно — T6.
3. **Регуляризация/обобщение [Г]:** весовое связывание по глубине — индуктивное смещение
   «алгоритмичности» (TRM: 7M бьют денсы на ARC; их авторы честно пишут: «why recursion
   helps… remains to be explained; we suspect overfitting, but have no theory») — наша
   открытая проблема TO-1, за неё не отвечаем, измеряем.

**Предсказание-дискриминант (две конкурирующие теории — мы обязаны их развести!):**
если мир Parcae (лупинг Pareto-выгоден даже без адаптивности) — неадаптивный контроль
AS-0 @iso-FLOPs всё равно должен бить денс-близнеца; если наш мир — выигрыш появится
только под адаптивным K(x). Эксперимент G1 имеет ОРУЖИЕ против обоих исходов. P-06, P-12.

## T3 [Т]. Критик — это обученная функция ценности, а остановка — оптимальное правило

**Постановка.** Конечный горизонт K_max, цена петли c, награда за остановку на шаге k:
A(x,z_k) − c·k. Требуется правило, максимизирующее E[награды].

**Лемма (оптимальная остановка для петель).** Пусть V(z_k) = ожидаемая финальная точность
при остановке «позже, оптимально». Пороговое правило «продолжаем, пока
E[z большего] − V(z_k) ≥ c» оптимально (стандартный конверт Снелла для конечного горизонта;
док-во — обратная индукция по k). При критике q̂ с sup-ошибкой ε сожаление
Regret ≤ 2ε·K_max/c`.

**Следствия для архитектуры (это и есть математика нашего ACT):**
- Голова q̂(z_k) — оценка V. Обучаем её TD-способом на верифицированных роллаутах
  (фаза B/C): цель — V-бутстрэп, метки — от верификатора (код исполнен, ответ сверен).
- Теневая цена c — единственная ручка «думай дольше» и она же объясняет budget-forcing:
  принудительный минимум петель = временное занижение c.
- Классический ACT (σ-halt с ponder-cost) выводится как частный случай при нулевой
  оценке выигрыша (q̂ ≡ const); критик-ACT строго богаче → ожидаем измеримый выигрыш
  (иначе LK-2 ложная, упрощаемся).
- **Свободный побочный продукт:** тот же q̂ — и есть процесс-награда для best-of-N/beam
  в TTC-движке. Одна голова закрывает остановку, выборку и поиск (у rStar PPM —
  отдельная 7B-сеть; у нас — голова с общими весами: −7B к памяти системы).

Предсказание: P-04. Убийца: критик-ACT не бьёт фикс-θ-ACT при равном бюджете петель
на dev-наборе → голова выбрасывается, остаётся θ-правило (T8).

## T4 [М]. Двухшкальное усреднение: зачем z_H и почему m предсказуемо

[СТАТУС 2026-08-24: ОТКРЫТА. m-sweep раунды 1–2 (TWEEK_RESULTS §7.1): предпосылка
«медленная карта сжимает» дважды не выполнялась — медленное состояние подчиняется тому же
закону T1′ (λ̂_L = 1.02–1.12). Раунд 3 со стабилизированным медленным контуром (LN(z_H) или
tanh-ограничение канала инъекции) — обязательный тест до любых архитектурных решений
двухмасштаба AS-1. Закон проекта: каждый рекуррентный контур ограничен без исключений.]

**Идея [Т-скетч, сингулярно-регулярная теория возмущений].** Быстрое состояние z_L
шагает по F_L(·, z_H); медленное z_H — по F_H раз в m шагов. Если F_L — λ_L-сжатие
при каждом фиксированном z_H, то z_L отслеживает квазиравновесие z_L*(z_H) с остатком
‖z_L − z_L*‖ ≤ λ_L^m · ‖старт‖, а z_H движется по усреднённому векторному полю;
ошибка усреднения O((1−λ_L^m)). То есть z_H — **обучаемые чекпойнты поиска**: быстрое
состояние может «откатываться» к плану, не помня его в изменчивом z_L. Именно этого
не хватало одношкальным петлям (и что HRM/TRM реализовали расписанием n:m вручную).

**Формула конструктива:**
```
m* ≈ ln(τ)/ln(λ_L)        (τ — допустимый остаток квазиравновесия, ~0.1)
```
Расчёт-пример B: λ_L=0.75 → m* ≈ 8.0; λ_L=0.85 → m* ≈ 14. Значит: **m — не гиперпараметр
для перебора, а вычислимый из телеметрии λ_L̂ после первого обученного чекпоинта.**
Качество(m) предсказанно унимодально: m≪m* — план шумит; m≫m* — план костенеет
(«overthinking», наблюдавшийся у всех луп-работ 2026, вкл. LoopWM/LARM-заметки).
Унимодальность, не монотонность. Предсказание: P-03 (m-развёртка на G1).

**Связь с DeepLoop:** их вывод «aligned inner cycles ⇒ показатель p=½» касается как раз
иерархических резонеров — наш двухмодульный вариант наследует их правило скейлинга
резидуалов α=(2N_g)^½, β=(8N_g)^(−½), что принято в спецификацию ядра (RESEARCH_V3 §4.3в).

## T5 [Т]. Петли × квантизация: шум копится ограниченно (и это измеримо)

**Лемма.** При шаговом шуме квантизации ‖ξ_k‖ ≤ δ(b) накопление
‖z_K − z_K^(clean)‖ ≤ δ(b)·(1−λ^K)/(1−λ) ≤ δ(b)/(1−λ) — **ограничено константой!**
(Док-во — та же геометрическая сумма из T1.) В отсутствие сжатия (λ≥1) шум копился бы
линейно/взрывно — собственно, это и была чума v1 (предсказание состояний чужого графа
без гарантии сжатия: KL улучшился на 10/16 переходах и умер). Вывод: **рекуррентная
система обязана доказать λ<1 до того, как ей разрешат тернарные веса** — порядок
ворот G1→G3 не бюрократия, а следствие леммы.

**Предсказание-убийца P-09:** просадка качества fp16→тернарно при K=16 относится к
просадке при K=1 как константа ≤ 1/(1−λ̂), БЕЗ сверхлинейного усиления. Если измерим
сверхусиление — лемма нарушена (систематическое смещение квантизации не нуль-среднее),
лечение: absmax-центровка или int4-фолбэк (разрешён заранее, §RESEARCH 8.G3).

## T6 [Р]. Цена токена и цена правильного ответа (бюджетная арифметика с константами)

Константы (Horowitz, ISSCC 2014, 45 нм; современные диапазоны указаны как коридор):
int8-MAC ≈ 0.2–1 пДж; fp16-MAC ≈ 1.5–4.6 пДж; SRAM 8kB-класса ≈ 5 пДж/32б (≈1.25 пДж/Б,
большой L2/L3: 2–10 пДж/Б); DRAM ≈ 640 пДж/32б (≈160 пДж/Б; современный HBM ≈ 50 пДж/Б).
Источник: Horowitz «Computing's Energy Problem», переводные таблицы SongHan/Stanford cs231n.

**Уз. 1 — цена петли против цены повторного чтения весов.**
K_free = b·e_mem / (2·e_MAC):
- тернарные веса (b=0.2 Б), горячий кэш: K_free = 0.2·(2..10)/(2·0.05..0.1) ≈ 2–20;
- против DRAM (50–160 пДж/Б): K_free ≈ 50–640.
**Тезис-проверка внешним числом:** BitNet-2B4T реально измерен 27 мДж/токен на CPU
(reddit-бенч, Ryzen 7845HX): наша оценка для 2.4B: весовой трафик 0.5 ГБ·50 пДж/Б = 24 мДж
+ ternary-FLOPs 4.8e9·0.05 пДж = 0.24 мДж → ≈24–27 мДж/токен. Совпало — модель цены валидна;
главный член — память, не арифметика. (`bitnet на CPU` = memory-bound, как и DECOD вообще.)

**Уз. 2 — токен нашей AS-1 (350M, тернарно, веса ~70 МБ):**
- Петля: 2·3.5e8 ternary-оп ≈ 0.035 мДж + чтение весов из горячего SRAM/L2: 70 МБ·3 пДж/Б
  ≈ 0.21 мДж. Итого ≈ 0.25 мДж/петля (горячий режим; холодный DRAM-разогрев амортизируется
  по длине последовательности).
- Токен при K̄=8: ≈ 2 мДж. Токен AS-2 (1.5B): ≈ 8–10 мДж.
**Уз. 3 — правильный ответ:** GSM8K-ответ ≈ 200 токенов: AS-1 ≈ 0.4 Дж/ответ.
Сравнение (порядок величин, batch=1): fp16-дeнс с ~50B активных параметров — только FLOPs
≈ 50–150 мДж/токен + весовой трафик десятки ГБ из DRAM ≈ джоули/токен → **энергетический
зазор ~10³ на токен** (в терминах аренды железа: ×5–30 дешевле стено-задачи; оба числа честны,
у них разные знаменатели — в SCOREBOARD E5 идут оба). Специально: наша оценка совпадает с
независимой оценкой из CALC06_OPUS v2 («база: вывод ×526 легче») — теперь впервые с
проверяемыми константами и внешним якорем (BitNet-бенч).
**Уз. 4 — вывод для дизайна:** память доминирует ⇒ (а) тернарность важнее FLOP-оптимизаций;
(б) петли до K~20–50 «почти бесплатны» относительно одного лишнего потока весов;
(в) главная скорость-рычаг всей программы — держать ядро в кэше (отсюда AS-1 ≤ ~100–150 МБ
и требование L2/L3-резидентности в рантайме G3). Предсказание: P-07.

## T7 [Р]. Знание ↔ веса: правило аллокации с числами

**Фактура к расчёту.** Эффективная ёмкость обученных весов: ~1–2 бита знания на параметр
(fp-экспозиции; оценки Allen-Zhu&Li «Physics of Language Models» и последующих).
Факт (сущность+связь+атрибуты, сжато): ~100–1000 бит → 50–500 параметров/факт →
в тернарных байтах: 10–100 Б/факт — хранение дешевле внешнего стора (DAM: 256 Б/факт,
измерено v2 EXP-05/06). **НО:** запись в веса стоит E≈10²–10³ экспозиций на факт
(надёжное извлечение), плюс интерференция, неудаляемость, хрупкость к промпту;
запись в DAM — O(d²) ≈ 10⁴–10⁵ FLOPs, редактируема, без интерференции.
**Формула-правило (рабочее, не претендует на теорему):**
```
внутреннизировать факт ⟺ (ожидаемые_доступы_за_жизнь × цена_доступа) ≥ цена_записи×E
⟺ частота запросов ≳ 10²–10³. Иначе — в стор.
```
Следствие для архитектуры: «энциклопедию» не кодируем — веса покупают только
**высокочастотные алгоритмические навыки**; факты пользователя, редкий хвост, всё
пост-cutoff — наружу (DAM + ретривер). Этим закрывается известная слабость
рекуррентных моделей (Huginn: фактическая память хуже дeнсов) без роста N.
Предсказание P-08 (сравнение плеч на 1k хвостовых фактах: DAM-плечо ≥ весовое при
≤1/10 обучающих FLOPs). Проверка масштаба стора: 10⁶ фактов × 256 Б = 256 МБ —
влезает в девайс-бюджет; при 10⁸ потребуется индекс (v2-машинерия: грубый скелет FF-16).

## T8 [Т]. Событийная граница ошибки: легализация интуиции v2 с гарантией

Эвристика v2 (H-04, «считать только когда удивлён») получает точный вид:
**Лемма (апостериорная оценка).** Если остановиться при ‖z_K − z_{K−1}‖ ≤ θ, то
‖z_K − z*‖ ≤ λθ/(1−λ). (Док-во: телескоп по геометрии сжатия.)
При λ=0.72 запас-критерий = 2.57·θ. То есть: **остаточная остановка с порогом θ гарантирует
ошибку ≤ 2.6θ — и это первое правило пропуска вычислений с доказанной границей, а не
калиброванным «в среднем» порогом** (как было в v1: «10/16 переходов, остальные хуже»).
Связь с T3: остаточное правило — дёшево и доказуемо при λ<1; критик-правило — дороже
(голова) и сильнее (учитывает награду); на G2 делается A/B: если критик не бьёт
остаток+θ, он удаляется (честная иерархия простоты). Предсказание P-05.

## Открытые проблемы (куда расти теории дальше)

- **TO-1.** Почему рекурсивное связывание весов улучшает ОБОБЩЕНИЕ (TRM-наблюдение без
  теории; у нас — гипотеза «алгоритмический индуктивный сдвиг» → измерить через
  transfer матрицу задач на G1–G2).
- **TO-2.** Предсказуемость λ(x) ДО генерации ответа (роутер сложности): можно ли оценить
  λ по первым k петлям (дисплейсменты сходятся быстро)? Если да — критик-остановка
  упрощается до «экстраполяции кривой уточнения» (дёшево, без головы).
- **TO-3.** Критик без разметки шагов: PPM-рецепт rStar (парные предпочтения) против
  нашей V-бутстрэп цели; сравнение на фазе C.
- **TO-4.** Стабильность: спектральная норма инжекций (Parcae negative-diagonal) против
  DeepLoop-показателя p=½ — A/B на G1, берём выжившее.
- **TO-5.** Looped-MoE: маршрутизация, расходящаяся по петлям, — спасение выразимости
  ядра без роста активных параметров; кандидат на AS-2+ после P-10.

## Связь теории с планом (как это перестаёт быть «красивой математикой»)

1. Каждое P-XX прибито к воротам (столбец выше); ворота не пройдены → правим теорию,
   не отчёт. 2. AS-0 существует ради P-01..P-03, P-06, P-12: это не «маленькая модель
   на неделю», а измерительный прибор теории. 3. Критерий «прорыва» (фиксируем заранее):
   P-01..P-03 подтверждены на двух масштабах { AS-0: 140M, AS-1: 350M }, и фит K-закона
   предсказал второй масштаб ДО его обучения (P-06). Тогда — оформление в статью.
4. Риск-честность: вероятность, что хотя бы одно из P-01..P-05 умрёт, — высокая
   (так и бывает с новой теорией). Смерть предсказания засчитывается как результат недели:
   заменяет главу теории на выжившую конкурентку и идёт в decision log.
