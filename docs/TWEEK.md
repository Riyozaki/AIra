# TWEEK: численный стенд верификации THEORY_V3
Статус: **протокол заморожен до прогонов** (предсказания TW-0…TW-4 записаны до измерений).
Дата заморозки: 2026-08-24. Коммит этого файла предшествует коммиту результатов — это и есть аудитный след.

## 0. Зачем
THEORY_V3 опирается на константы, которые до сих пор взяты из чужих статей или из логики:
λ (сжатие рекуррентной карты, T1), форма E(K) (T1/T2), λ_L и m* (T4), таблица конкуренции форм законов (T2/P-12).
От λ̂ зависит калибровка долга в L1_SPEC (`D ← λ̂·D + Δ̂`), от m* — конфиг двухмасштаба AS-1.
T-неделя = стенд, который эти константы **измеряет**, с заранее записанными предсказаниями и ценой смерти.

Принцип (протокол проекта, п.0): теория → предсказание → расчёт → эксперимент → чекпоинт.

## 1. Ограничения стенда (честно)
- Железо стенда: 2 CPU, 3 ГБ RAM (HW-0 соблюдён с запасом — это хуже, чем T1).
- **TW-H (отложено, не отменено):** λ̂ на реальных весах Huginn-3.5B невозможен на 3 ГБ RAM. Переносится на T0-конфиг (G0/G1), способ измерения уже реализован в `lab/telemetry.py` и протестируется здесь на toy-ядре.
- Публичные кривые берём из статей с явной пометкой происхождения каждой точки (таблица / оцифровка графика).

## 2. Установка эксперимента
Задача: двухмасштабный марковский источник (`lab/data_synth.py`):
- быстрый уровень: x_{t+1} = (x_t + step_s) mod V, step_s = 1+s, s ∈ {0..3}, V = 24;
- медленный уровень: s переключается с вероятностью 1/τ на шаг, τ = 10 (известная правда);
- шум: с вероятностью 0.05 эмиссия равномерна (даёт ненулевой пол ошибки → E(K) обязан иметь пол);
- «трудные» позиции: 0–2 токена после переключения s (там нужна новая инференция s) — метрика split hard/steady.

Ядро (`lab/models.py`): один трансформер-слой с общими весами, итерируемый K раз (h ← h + β·f(h)),
варианты: с/без depth-embedding (тест на автономность карты), двухмасштабная версия
(быстрый слой каждый шаг + медленный блок каждые m шагов с FiLM-инъекцией).

## 3. Операционализации (как именно меряем — зафиксировано до прогонов)
1. **λ̂_disp** (осн.): прогон K=64, d_k = RMS(h_{k+1} − h_k) по батчу; фит log d_k = a + k·logλ
   в окне d_k > 10⁻³·max(d). CI — бутстрэп 200 по батчам.
2. **λ̂_pert**: в точках траектории h_k возмущение ε (‖ε‖ = 0.01·‖h‖), q = ‖R(h+ε) − R(h)‖/‖ε‖,
   8 направлений × батчи. Локальный Липшиц.
3. **λ̂_J**: power iteration (12 ит.) над JVP Якобиана карты R в h_k → спектральный радиус (оценка сверху).
4. **λ̂_E(K)**: val-loss по шагам надзора k=1..64; фит L(k) = L∞ + C·λ^k профильным сканом по L∞.
5. **λ(x) по токенам**: per-token фит наклона log d_k на окне k∈[2,20] → распределение (медиана, квартили, R²).
6. **λ̂_L** (медленный контур): сжатие медленного состояния между применениями, приведённое к шагу среды: λ̂_step = (d^s_{j+1}/d^s_j)^(1/m).

## 4. Предсказания (записаны ДО прогонов; цена смерти при каждом)
- **TW-0 (валидация инструмента).** Три метода (disp / pert / J) согласуются на обученной карте в пределах ±20%.
  *Если нет — инструмент сломан: чиним инструмент, выводов не делаем. Инструмент важнее результата.*
- **TW-1 (существование сжатия, T1).** После обучения λ̂_disp ∈ [0.55, 0.95].
  *Кил/пересмотр:* λ̂ ≥ 1.0 → карта не сжимает → T1, T5 (δ/(1−λ)) и σ-δ-долг L1 недействительны в текущем виде;
  обязаны за 72 ч либо перейти к λ-семейству ядра (h ← λ·h + (1−λ)·f(h)), либо убить L1-долг как механизм.
- **TW-1b (контроль на init и β).** При случайном init λ̂ ≈ 1.0 ± 0.15 при β=1 и монотонно убывает с β ∈ {0.5, 0.25, 0.125};
  после обучения λ̂ < λ̂_init(β=1). *Если обучение не снижает λ̂ — гипотеза «сжатие покупается обучением» отвергнута на toy-шкале.*
- **TW-1c (автономность).** λ̂ одинаков ±10% с и без depth-embedding. *Иначе T1 работает только для неавтономных карт — теорию переписать под R_k.*
- **TW-2 (форма E(K)).** Геометрический фит с полом: R² ≥ 0.9 и |λ̂_E(K) − λ̂_disp| ≤ 15%·λ̂_disp.
  *Поправка TW-2′ (записана заранее):* если pooled-кривая не геометрична, но медианный per-token R² ≥ 0.8
  и квартили λ(x) различаются ≥ ×2 — T1 уточняется до «λ распределён по токенам» (это прямое обоснование
  адаптивной глубины и критика T3, а не фейл). Полный фейл: ни pooled, ни per-token не геометричны → T1 пересмотреть.
- **TW-3 (двухмасштаб, T4).** Задача с τ=10; по измеренному λ̂_L(m=1) вычисляем m*_pred = ln τ / ln(1/λ̂_L).
  Эмпирический argmin_m val-loss попадает в [m*_pred/2, 2·m*_pred].
  *Кил:* argmin/m* вне [0.5, 2] → T4 отвергнута на toy-шкале; конфиг AS-1 строится без двухмасштаба до новой теории.
- **TW-3b (экономия — смысл теоремы).** m=1 (медленный блок каждый шаг) статистически не лучше m*.
  *Иначе двухмасштаб не экономит, а просто не мешает — ценность T4 падает до «нейтрально» (фиксируем честно).*
- **TW-4 (публичные кривые, P-12-dataset).** На точках Huginn (качество vs число рекуррентов r):
  геометрический-закон-с-полом побеждает чистый степенной (мир Parcae) по AICc (Δ ≥ 2).
  *Кил:* степенной лучше → наш E(K)-закон не подтверждён в чужой системе, T2 помечается «мир Parcae»,
  ставка адаптивности K(x) ослабляется, L1-SPEC не бастует, но его PB-предсказания переформулируются.

## 5. Запуски
- `lab/exp_lambda.py`: init-sweep β×{0.125,0.25,0.5,1.0} (без обучения) + 3 обученных прогона (DE off; DE on; β=0.5 DE off), 3500 шагов.
- `lab/exp_msweep.py`: m ∈ {1,2,4,8,16,32} + baseline без медленного блока, 1800 шагов каждый.
- `lab/public_fit.py`: фиты по `lab/public_curves/*.json` (Huginn/Parcae/Loopie; происхождение каждой точки — в файле).
Артефакты: `results/tweek/*.json` (+ .png если доступен matplotlib). Итог — `docs/TWEEK_RESULTS.md`.

## 6. Что стенд НЕ решает (зафиксировать, чтобы не переобещать)
λ̂ toy-ядра ≠ λ̂ 400M-ядра; задача TW-недели — проверить *форму законов и согласованность методов*,
а не абсолютные значения для AS-1. Перенос констант на живой масштаб — отдельное предсказание PB-04 (уже в L1_SPEC: перенос ±20%).
