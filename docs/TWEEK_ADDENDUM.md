## Что показал валидационный прогон (до фикса)
1. **Инструмент сошёлся идеально (TW-0 пройден на init):** λ̂_disp = λ̂_pert = λ̂_J = 1+β с точностью
   4 знака на β∈{0.125,0.25,0.5,1.0} (disp R²=1.000). Закон init-карты: **λ_init = 1 + β·‖f′‖, ‖f′‖≈1**.
2. **TW-1b про β=1 провалено как записано:** λ_init(β=1) = 2.00, а не 1.0±0.15. Механизм подтверждён
   (h+h·f с пре-нормой даёт ‖f′‖≈1 → экспансия ≈ 1+β). Формулировка TW-1b была неверна, закон — верен и полезен.
3. **TW-1 провалено как записано на этом стенде:** после 200 шагов λ̂ остаётся 2.0000 по норме,
   равномерно по токенам (q25=q75=2.0). d_k растёт ~×2/итерацию до inf; val-loss по k РАСТЁТ
   (2.20→2.03→…→2.159, NaN на k≥54). L_hard/L_steady отравлены NaN.
4. Диагноз конфаунда (записывается до проверки): двухмасштабный марковский источник решается
   в 1–2 слоя вниманием — **петлям нечего итерировать** → обучение не формирует сжимающую динамику;
   плюс LayerNorm на выходе делает лосс инвариантным к норме состояния → норма свободно убегает.
   Инструмент исправен (TW-0), ломаны задача и метрическое пространство. По TW-0 чиним стенд.

## Фикс стенда (фаза A2), три элемента
- **Задача с истинной глубиной вычисления:** клеточный автомат, правило 110, r=8 шагов эволюции
  (CASource, `lab/data_synth.py`). Ответ требует композиции r последовательных преобразований —
  петли здесь не опция, а необходимость. Ground-truth глубина известна.
- **Метрика в фактор-пространстве:** угловой дисплейсмент d^dir_k (косинусная геометрия направления h_k)
  в дополнение к норм-метрике. LN-чтение факторизует масштаб — содержательная конвергенция живёт
  в направлении. Обе метрики сообщаются всегда парой.
- **Вариант ядра со связанным состоянием:** `state_ln` (h ← LN(h + βf(h))) — состояние на сфере,
  динамика ограничена по построению; сравнение с сам-ядром на одинаковом бюджете.

## Предсказания фазы A2 (до прогонов, кил-критерии при каждом)
- **TW-A1 (санити глубины).** На CA acc ответа при K_eval=16 выше, чем при K=1, на >20 п.п.
  при K_train≤12. Иначе CA тоже не провоцирует глубину → стенд чинить дальше (r↑, правило сложнее).
- **TW-A2 (норма).** sum-ядро останется экспансивным по норме (λ̂_norm>1); ln-ядро пинует норму.
  Предсказание в том, что λ̂_norm sum-ядра НЕ снизится ниже 1.5 — норма не является информативной
  осью для LN-моделей; выводы по сжатию делаем только по направлению.
- **TW-A3 (главное).** На CA после обучения λ̂_dir ∈ [0.5, 0.95] (оба ядра), причём сжатие направления
  видно в области k≥r; квартили per-token λ̂_dir различаются ≥×1.5 (гетерогенность λ(x) —
  предтеча адаптивной глубины, T3). Кил: λ̂_dir ≥ 1 у обоих ядер → T1 фатально неверна для
  рекуррент-глубины вообще → пересмотр T1/T5/L1-долга (72-часовой редизайн), результаты —
  негативный артефакт с полной телеметрией.
- **TW-A4 (плато E(K)).** Для ln-ядра: L_ans(k) убывает до k≈r, затем плато с деградацией <5%
  вплоть до K=64. Кил: деградация >5% от k=16 к k=64 → «длинные петли на инференсе недопустимы»
  для ln-ядра → вся стратегия test-time compute требует другого ядра (фиксируем и идём в λ-семейство).
- **TW-A5 (контроль конфаунда).** На two-time задаче с длинным бюджетом (2500 шагов, K_train≤12)
  λ̂_dir ≥ 1 (сжатие НЕ рождается там, где петли не нужны). Если родится — наш диагноз конфаунда
  неверен, что тоже находка (фиксируем).
