# FEATURES.md — разведка фичей чужих LLM-стеков → план переноса в LeanCore

Источники: Kimi Linear (arXiv 2510.26692), DeepSeek-V3 (arXiv 2412.19437), Qwen3 TR (arXiv 2505.09388),
Gemma 3/4 QAT-релизы (google), Anthropic Constitutional AI (2022+2026 spec), Muon (Keller Jordan, modded-nanogpt).

## Разобранные фичи и вердикты для нашей шкалы

| Фича (откуда) | Суть | Вердикт для LeanCore |
|---|---|---|
| **KDA — channel-wise decay + delta rule** (Kimi Linear) | Затухание по каналам (а не по головам) + delta-правило: состояние-матрица S, rank-1 коррекция `S ← Diag(α)S + β(v − Sᵀk)kᵀ` | **ПЕРЕНОСИМ**: у нас уже канальный α (как KDA), добавляем delta-правило (матричное состояние). Это прямой апгрейд нашего EMA-блока. Фича B. |
| Гибрид 3:1 (KDA:MLA) + NoPE (Kimi) | Глоб. attention раз в 4 слоя; поз-кодирование отдают линейному слою | У нас attention победил изо-цену ранее — гибрид противоречит нашей цели (поток без кэша). НЕ берём, но τ-гейт и pos — уже NoPE-совместимы. |
| **MTP multi-token prediction** (DeepSeek) | Доп. головы предсказывают t+2,...: плотнее сигнал обучения + спекулятивный дикод (85–90% accept на 2-м токене) | Спекуляция НЕ ускоряет RNN-стриминг (нет батча верификации). НО как **обучающий сигнал** — берём: aux-голова t+2 с весом 0.1. Фича D. |
| **Aux-loss-free MoE** (DeepSeek) | Эксперты с bias-коррекцией маршрутизатора вместо aux-loss; квантование активаций FP8 | **ПЕРЕНОСИМ top-1 MoE-FFN** (4 эксперта оф F/2, bias-баланс): меньше активных FLOP/токен. Фича C. |
| **Strong-to-weak distillation** (Qwen3) | Малые модели учатся на логиты больших; > RL по эффективности | **ПЕРЕНОСИМ**: champ4k → student (D=128, L=3): CE + KL(T=2). Ось сжатия с сохранением качества (та же цель, что Gemma-QAT). Фича E. |
| Thinking/non-thinking budget (Qwen3) | Переключение режима «думать»; бюджет токенов мышления | Прямого аналога нет (нет reasoning-данных). **Наш аналог — τ-гейт ADR: бюджет вычислений на токен** + бюджет max_tokens в обвязке. Документируем как соответствие. |
| **Gemma QAT рецепт** | ~5k шагов QAT-файнтюна с дистилляцией от fp32-чекпоинта; статичные скейлы активаций; выборочный 2-бит | У нас QAT-400 уже работает; добавляем: (а) QAT с KL-целью к fp32-учителю (= Gemma рецепт буквально), (б) опцию статичных скейлов активаций. Часть фичи D/E. |
| **Constitutional AI** (Anthropic) | Конституция → self-critique → revision → RLAIF | Напрямую для 2.6M-модели нереально (качество критика). Переносим **обвязочную часть**: файл-конституция как системный промпт + self-revise проход (draft→critique→revise) как протокол инференса. Фича A3. |
| **Muon optimizer** (KellerJordan) | Momentum + Newton–Schulz ортогонализация обновлений 2D-матриц; −35% времени обучения NanoGPT | **ПЕРЕНОСИМ**: Muon для 2D (Wm/fc1/fc2/E), Adam для скаляров/смещений. NS5 — numpy-реализация. A/B при равных шагах. Фича B2. |
| FP8 training (DeepSeek) | Смешанная точность | Не применимо в numpy-разведке; у нас QAT уже покрывает инференс-ось. [не берём] |
| MLA (латентное сжатие KV) | Для attention-кэша | Нет attention ⇒ не применимо. [не берём] |

## План имплементации (каждая фича = измеримый A/B, отдельный коммит)

- **Фича A (обвязка)**: sampling в lc_stream (temp/top-k/top-p) + `lc_repl.py` (токенизатор из meta.json, интерактив, системный промпт/«конституция», бюджет токенов); service-mode по HTTP (один бинарник, OpenAI-подобный /v1/completions минимум).
- **Фича B (KDA-lite)**: `nano_kda.py` — delta-rule состояние (D×D) с канальным α; BPTT руками + gradcheck; A/B vs EMA при равном бюджете.
- **Фича B2 (Muon)**: `--opt muon` в тренере; A/B vs Adam при равных шагах.
- **Фича C (MoE)**: `nano_moe.py` — top-1 aux-loss-free FFN; PPL@step и tok/s обучения.
- **Фича D (MTP-aux)**: вторая голова t+2 (вес 0.1, shared E), измерение ΔPPL обучения.
- **Фича E (distill)**: champ4k → student 1.1M params, CE+KL, сравнение с from-scratch.

Каждая фича включается флагом и обязана пройти gradcheck/валидацию; отрицательные результаты фиксируются как раньше.
