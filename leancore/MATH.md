опы ≤ 5e-7, сквозные модели (hybrid, ema+ADR) ≤ 7e-5. [верифицировано]

## 3. Forward-стоимость на токен (тело; голова отдельно)

MAC/ток attn-блок: проекции 4d²=147 456; скоры+взвешивание 2·(2·T·d)=73 728; MLP 2·d·F=221 184 → **442 368**
MAC/ток EMA-блок: рекурсия ~5d=960 + Wm d²=36 864 + MLP 221 184 → **258 048 (−41.7%)**

Голова: V·d = 1 536 000 MAC/ток — 46% всех MAC у attn-модели, 60% у ema-модели.

## 4. Точка перелома attention vs EMA по T

Скоры attention/токен: 2·T·d MAC. EMA-рекурсия: ~5d, константно. Скоры дороже проекций (4d²)
при **T ≳ 384 (=2d)**, дороже всего остального блока при **T ≳ 960**. На T=96 скоры — 16.7% блока.

## 5. Выводы backward (nano_lc.py) — всё FD-проверено

- **softmax+CE**: ∂L/∂z = (p − onehot(y))/(B·T) [4.2e-7]
- **LayerNorm**: v = γ⊙dy; dx = (istd/N)⊙(N·v − Σv − x̂⊙Σ(v⊙x̂)); dγ=Σ(dy⊙x̂); dβ=Σdy.
  ⚠️ γ умножает dy ДО редукций — порядок скобок критичен (поймано FD, [1.8e-8] после фикса)
- **GELU-tanh**: dg/dx = ½(1+t) + ½x(1−t²)·k₀(1+3cx²), t=tanh u, u=k₀(x+cx³) [4.8e-7]
- **attention**: dV=AᵀdY; dA=dY Vᵀ; dS=A⊙(dA−Σ(A⊙dA))/√d_h; dQ=dS·K; dK=dSᵀ·Q [1.0e-7]
- **EMA** (моё): λ_t = c⊙(∂L/∂y_t) + a⊙λ_{t+1}, c=scale; ∂x_t=(1−a)⊙λ_t;
  **∂θ = Σ_t λ_t⊙(h_{t−1}−x_t)·a⊙(1−a)**, h_{−1}≡0 — граничный член обязателен [3.2e-8]
- **AdamW**: m̂/(√v̂+ε) + decoupled wd·θ.

## 9. Математика ADR-роутера (форвард + полный backward) — [верифицировано FD]

Форвард: s_t = wᵀx_t + b; S = top-k по s (k=round(φ·T)); g_t = σ(s_t);
out_t = x_t + g_t·Δ(x_S)_t при t∈S, иначе out_t = x_t.

Backward (dH = ∂L/∂out):
1. t∉S: ∂L/∂x_t = dH_t.
2. t∈S: ∂L/∂Δ_t = g_t·dH_t ⇒ dx_arm = J_Δᵀ(g⊙dH_t); dx_t = dH_t + dx_arm. **Без второго g!**
3. Роутер: ∂L/∂s_t = ⟨dH_t, Δ_t⟩·g_t(1−g_t); dw = Σ_S ds_t x_t; db = Σ ds_t;
   **∂L/∂x_t ⊕= ds_t·w** (путь через скор — обязателен).
4. Эмбеддинг-lookup: np.add.at(g_E, ids, dX) — член нельзя терять.

Найдено этой проверкой (история сессии, все − [измерено]): потерянный E-член (err 2.0),
пропущенный ds⊙w (1.22), лишний g (1.09e-4). После фиксов: 4.3e-5.

## 11. Потоковый (инкрементальный) инференс EMA — [верифицировано + измерено]

h_t = a⊙h_{t−1} + (1−a)⊙x_t ⇒ потоковый forward ТОЧНО равен оконному (max |ΔNLL|=2.9e-6, чистая
EMA); граница чанка T: сброс состояний ≡ семантике тренировки. ADR в потоке: порог σ(s)≥τ
(τ=0.4 ⇒ участие ~52% ≈ обученных 55%; качество измерено: композит Δ −0.5% PPL против оконного).

Результаты см. README (итоговые таблицы) и `results/`.
