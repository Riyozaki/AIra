## 0. Инвентарь уже существующего (становая ось)

- Оптимизаторы: **AdamW** (b1 0.9 / b2 0.95 / wd 0.1) и **MuonW** (моментум 0.95 + NS5-ортогонализация
  для 2D; Adam-ветка для скаляров/LN/эмбеддинга).
- Расписание: warmup 60 → косинус до 0.1·lr.
- Лосс: полный CE + **sampled softmax** (K=512 негативов из unigram-предложения, logQ-коррекция,
  цели всегда в наборе; аннилинг на полный CE в последние 12% шагов).
- Данные: случайные окна каждый шаг (rng-сдвиги — «augmentation» уже встроен).
- Aux: MTP-голова t+2; KL-дистилляция; MoE top-1; ADR-роутер глубины.
- Вал: всегда полный softmax, фикс-rng.

Механизм [гипотеза]: NS-ортогонализация выравнивает апдейт по спектру → на 192d сетке и 1M корпусе
лучше удерживаются редкие направления (zipf-хвост). Цена: NS5-итерации ~ −9…12% tok/s — окупается,
финал: −3.4% PPL и минимум достигнут на ~1400 шаге (≈ изо-качество ×1.07+ wall). **Muon принят как оптимизатор по умолчанию** для следующих прогонов (честная оговорка: один сид; до повышения в «стандарт» — повтор на втором сиде).
